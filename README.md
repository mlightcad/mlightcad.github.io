# MLightCAD Homepage

Brand site for [MLightCAD](https://github.com/mlightcad), featuring [cad-viewer](https://github.com/mlightcad/cad-viewer).

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Deployed to GitHub Pages at https://mlightcad.github.io/ via `.github/workflows/deploy.yml`.
